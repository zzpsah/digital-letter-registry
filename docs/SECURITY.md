# Security and Privacy

| Class | Examples | Repository policy |
| --- | --- | --- |
| Public | Source code, synthetic fixtures, generic documentation | May be committed |
| Private operational | Letters, scans, metadata, extracted text, logs | Never commit |
| Secret | Passwords, keys, tokens, database URLs, sessions | Never commit or print |

Before live use, require authenticated least-privilege access, private storage, suitable encryption and backups, auditability, validated document handling, and a reviewed retention policy.

No live control is implemented or verified.
