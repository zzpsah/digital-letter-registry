# Project Memory

The user receives large numbers of official school/department PDFs and images, frequently through WhatsApp. The long-term pain is retrieval: filenames are meaningless and exact memo numbers/dates are usually forgotten.

The user remembers **context** instead: subjects, tasks, department, year, deadline, category, or phrases such as `inter exam last date` or `UDISE PEN correction`.

Therefore this project must behave like a private searchable memory:

`Upload → Preserve → Extract/OCR → Understand → Smart Rename → Index → Search → Open Original`

Important preferences:
- Hindi-first government/education content.
- OCR need not be perfect if enough context is recovered.
- AI may infer meaning from broken OCR and common government language.
- Exact facts are verified from the original.
- Smart filenames must help even in ordinary Drive/file searches.
- Web search must provide optional date/category/authority filters.
- Old documents must be recursively reprocessable when rules/models improve.
- Keep the user workflow close to “forward/upload and forget”.


## Project operating memory

- Repository-local rules and evidence are authoritative over chat memory.
- Before meaningful implementation/integration work, read README/RULES/AGENTS, relevant docs, `.ai/`, root tasks, and the relevant `brain/` enhancement context.
