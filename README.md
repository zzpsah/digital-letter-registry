# Digital Letter Registry

A privacy-first, Hindi-first registry for preserving, organizing, searching, and understanding letter archives.

## Status

This DevOS-managed repository currently contains product planning and governance only. No application, database, OCR pipeline, AI integration, private document, or deployment has been implemented.

## Direction

- Preserve originals as immutable private records outside Git.
- Store structured metadata and searchable extracted text with provenance.
- Use local OCR/text extraction first; keep assisted analysis replaceable.
- Design for Hindi-first content, accessibility, mobile use, and low bandwidth.
- Never commit letters, identifiers, credentials, or archive content.

See PRD.md, docs/ARCHITECTURE.md, and brain/README.md.

## Workflow

READ -> UNDERSTAND -> PLAN -> IMPLEMENT -> TEST -> REVIEW -> FIX -> COMMIT -> UPDATE DOCUMENTATION

No production deployment or live data import is authorized by this scaffold.
