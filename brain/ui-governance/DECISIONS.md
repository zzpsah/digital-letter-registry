# Decisions — UI Governance

1. **Preserve, do not redesign.** Existing accepted interface is the baseline.
2. **Hinglish is the default display label.** Internal compatibility value `mixed` may remain.
3. **Search stays hybrid and resilient.** Generative AI must not become a hard dependency for normal search.
4. **Recoverability over destructive convenience.** Documents and recipients use restore-capable removal paths.
5. **Admin controls remain admin-only.** Authorization must be enforced server-side.
6. **Source-grounded language.** Hindi/Hinglish content may retain official English technical terms.
7. **Small patches.** Alter only the requested surface and preserve visual tokens/layout unless explicitly instructed otherwise.
