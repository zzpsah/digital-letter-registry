# UI Governance Enhancement Brain

Purpose: preserve the accepted eLetters UI/UX and prevent future AI/tools from performing broad redesigns or silently changing established workflows.

Authoritative design contract: `docs/UI-DESIGN-CONTRACT.md`.

This enhancement brain must be read before any work that changes navigation, visual styling, authentication UX, search UX, language controls, recipient controls, delete/restore behavior, admin layout, or document cards.
